## 已修正或未采纳的说法

- **范围查询右侧列“一律失效”**：D04第34页表述过度简化。要分别看索引区间、后续过滤、覆盖和执行计划；Q30不按这句背诵判分。
- **AOF重写“完全不阻塞”**：D04第29页的简化说法不作为评价依据。fork、内存与I/O压力等需按实际版本和官方资料另查，本次没有新增此标准答案。
- **Kafka配置后“消息绝不丢”**：D04第31页只作话题线索；具体承诺取决于故障模型、副本、确认、重试和消费处理，不能用几个参数保证所有场景。
- **项目100%指标**：D03第2—3页展示不同版本与样本，未复现实验；仅支持追问样本、基线、分母和版本，不证明任何新任务都成功，也不能写进候选人的经历。
- **固定字符阈值与记忆TopK**：D03第76—78页的配置仅属示例；字符数不是Token数，需验证关键事实保真与任务效果。
- **产品排名、订阅经历与品牌必用**：D03第135—137页属个人体验或建议，不要求候选人使用指定付费产品，不把偏好与未核实产品行为转成评价标准。
- **恢复能力的版本差异**：D03第2页的恢复指标与第90页“尚无复杂一致性检查”不可拼成同版已实现事实。Q19的漂移检查是训练要求与可行设计，不宣称材料某版已经实现。
