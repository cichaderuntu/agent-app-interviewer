# Agent 应用开发面试官 Skill

面向国内校招与实习的 Agent／AI 应用开发模拟面试技能。根据简历、项目经历与目标 JD 动态出题，一次一问，结束后结合实际回答证据复盘。

## 能做什么

- 围绕个人职责、实现机制、技术取舍与项目效果追问。
- 覆盖 RAG、工具编排、上下文与记忆、评测、后端、AI Coding 和算法。
- 提供 50 张题卡、100 条针对性追问和弱项复练变体。
- 默认 6 个核心问题，每题最多 2 次追问；支持调整题量和方向。
- 无简历或 JD 时，可直接开始通用基础与场景面试。
- 接受合理的替代实现，区分回答不足、未覆盖内容与经过提示的表现。

## 使用

让支持读取本地技能文件的 Agent 加载整个 `agent-app-interviewer` 目录，并读取其中的 `SKILL.md`。这个技能没有运行时代码、API Key 或第三方包依赖；是否需要安装到技能发现目录，由使用的平台决定。

在可以读取本仓库文件的会话中，可直接使用：

```text
请读取 agent-app-interviewer/SKILL.md，根据我的简历和以下 JD，
做一轮 Agent 应用开发实习模拟面试。一次一问，结束后统一复盘。

简历／项目：……
目标 JD：……
```

没有材料也可以：

```text
请按 agent-app-interviewer/SKILL.md 直接开始模拟面试，
今天只练 RAG 和工具调用，共 4 个核心问题。
```

面试中可以说“提示一下”“跳过”“结束并复盘”；结束后可以说“只复练这次的薄弱项”。缺失历史记录时，技能会说明限制，不会虚构上次的表现。

## 文件结构

```text
agent-app-interviewer/
├── SKILL.md                    技能入口与面试规则
├── agents/openai.yaml          界面元信息
└── references/
    ├── session.md              选题、预算与会话记录
    ├── assessment.md           证据评价、复盘与复练
    ├── question-index.md       题卡索引
    ├── cards/                 按主题分组的题卡
    ├── sources.json           来源账本
    └── technical-grounding.md  官方技术参考与判定边界
```

技能文件全部使用相对路径，可以随整个目录一起迁移。日常使用无需一次加载所有题卡。

## 资料与评价依据

初始资料快照日期为 **2026-10-16**，包含 11 条岗位 JD、18 篇面经／求职复盘、2 条社区讨论、4 条待核验招聘线索，以及补充核验的 10 条官方技术参考。

来源链接、原文可读状态、日期限制和岗位状态保存在 `sources.json`。岗位资料含历史样本，不能据此认定仍有名额。面经属于作者自述；待核验线索不参与题卡评价标准。

题卡的考察点、必要证据、追问和复练设计是 AI 辅助整理的训练规则，不是公司官方题库或评分标准，也不代表行业考查频率。官方技术资料只支持其注明的范围，不为整张题卡背书。

复盘不提供未经校准的总分、录用概率或招聘结论。候选人的简历和回答默认留在当前会话，明确要求导出时才保存。

当前维护日期为 **2026-10-17**：共14条岗位JD、21篇网络面经、2条社区讨论、4条待核验线索、18条官方技术参考及4份用户文档（共63条来源）。PDF选读包含8段面经章节，按汇编文件记为D类，不额外算作8篇独立原帖；历史样本与参考回答的限制逐条保留。

本次PDF补充8个考点并完善10道既有题目，共18题增加条件化参考回答。详见 [文档选读与面经摘编](agent-app-interviewer/references/pdf-import-notes.md)。原PDF、全文提取、个人材料和临时密钥不进入技能包。

## 后续扩充

新资料按“核验来源 → 去重 → 补充已有题卡或新增题卡 → 核对技术依据 → 同步索引 → 校验”维护：

1. 在 `references/sources.json` 记录来源及其日期、读取状态和限制。
2. 相同考点优先补充已有题卡；新考点使用新的题号，保留已有编号。
3. 新题补齐考察点、必要证据、替代方案、追问触发条件、停止条件与复练变体。
4. 更新 `question-index.md`、数量说明及相关主题路由，检查所有引用和本地链接。
5. 涉及面试行为的调整，用实际模拟场景验证后再发布新版。

本聊天已约定每周一 **14:00（北京时间）** 发起更新申请，首次为 **2026-10-19**。实际定时触发由桌面应用任务管理；复制仓库不会自动创建定时任务。电脑需开机且桌面应用保持运行。

每周先申请，用户同意后才检索、更新并同步私有 GitHub 仓库；未回复不执行、批准不跨周复用。默认每轮最多20条有效新增来源、10张新题卡，不设最低数量。普通模拟面试不会触发维护。

执行方法见 [每周增量维护](agent-app-interviewer/references/maintenance.md)。研究记录、申请状态和发布记录保存在被忽略的本地 `research/weekly-maintenance/`，不随技能上传。

维护工具仅使用 Python 3.10+ 标准库（Windows可用 `py -3.14` 替代 `python`），不影响面试功能的无依赖使用：

```sh
python agent-app-interviewer/scripts/validate_bank.py
python -m unittest discover -s agent-app-interviewer/scripts/tests -v
```

检查包含题卡字段、来源引用、待核验线索限制、索引与数量一致性；传入 `--baseline <上一版本技能目录>` 还会检查历史编号未被删除。脚本校验不替代原文核验和追问质量审查。
